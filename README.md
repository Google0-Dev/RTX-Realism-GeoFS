## ✅ What does this add-on include ?

This Add-on delivers a profoundly immersive experience by integrating advanced visual fidelity—featuring soft, extended-distance shadows, atmospheric fog, and automated day/night color and contrast grading—with dynamic physics simulations including 3-axis procedural turbulence, simulated wing flex, ground effect lift, and responsive cockpit camera shake.

## ⚠️ Configuration

shadows: { enabled: true,                               
           size: 2048,
           softShadows: true,
           darkness: 0.45, Higher The number Less Darker
           maximumDistance: 15000 }, Higher the number Slower but More Distance
           
You could always change these settings For Better Experience.           

## How to Install This Add-on ?
### Method 1: Tampermonkey (Recommended)

> [!IMPORTANT]
> Ensure the extension has all necessary permissions and is enabled.

This method only needs to be set up once. After that, the add-on will load automatically.

Open the [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) Dashboard and click the tab with the plus (+) sign.

Clear any existing code in the editor and paste the RTX-Realism.js code.

Click on File, then select Save.

### Method 2: JavaScript Console 

> [!NOTE]
> This method requires you to manually paste the code into the console every time you launch GeoFS.

Open the Inspect Panel in your browser by pressing F12, or by right-clicking anywhere on the webpage and selecting Inspect (or Inspect Element).

Navigate to the Console tab and paste the RTX-Realism.js code.

(You may be prompted to type "allow pasting" into the console before you can paste the code).
